# Contribuindo para o projeto ZerÓbito

Obrigado por se interessar em contribuir com o projeto! 🙌  
Para manter o projeto organizado e com qualidade, siga estas orientações básicas.

---

## Tipos de contribuições aceitas

Atualmente, aceitamos os seguintes tipos de contribuições:

1. **Implementar novas features**  
   - Baseadas em **user stories já documentadas** nas **issues** do repositório.  
   - **Não é permitido desenvolver algo sem uma issue correspondente**.  

2. **Adicionar testes automatizados**  
   - O objetivo é **aumentar a cobertura de testes**.  
   - Certifique-se de que os testes estão **passando localmente** antes de submeter a PR.

3. **Revisão de código (Code Review)**  
   - Apontar bugs, vulnerabilidades ou code smells.  
   - Dar feedback claro e construtivo.

---

## Fluxo de contribuição

1. **Fork e clone o repositório**:

2. **Crie uma branch para sua contribuição**:

    * Use o padrão "tipo de contribuição"/"nome", por exemplo:
      * feat/cadastro_usuario
      * tests/cadastro_usuario
      * fix/bug_cadastro_usuario

3. **Faça suas alterações**

4. **Commits**

   * Use mensagens de commit claras e objetivas


5. **Pull Requests** 
   * contra a branch `main` do repositório principal.
   * Explique claramente **o que foi feito**.
   * Referencie a **issue correspondente**, se houver.


## Boas práticas

* Mantenha o código **limpo e legível**.
* Atualize a **documentação** se necessário.
* Não inclua arquivos de configuração local ou sensíveis (`.env`, `node_modules`, etc.) na PR.

---

Muito obrigado por contribuir! 🚀
Seu esforço ajuda a manter o projeto ZerÓbito cada vez melhor.
